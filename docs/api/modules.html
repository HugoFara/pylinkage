pylinkage

The packages below are listed alphabetically. To define and simulate a mechanism you need four of them, in this order: pylinkage.components (frame points), pylinkage.actuators (motor inputs), pylinkage.dyads (the constrained pairs that close the loops) and pylinkage.simulation (the Linkage container). The getting started tutorial walks through them; the rest are what you reach for afterwards.

A name is public when it appears in a package’s __all__; modules inside a package are implementation. See Deprecations for the rule and for every name currently on its way out.
